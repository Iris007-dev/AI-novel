## 章型判定规则

context-agent 在写章前必须根据以下信息判定本章章型：

1. **章纲标注**：如 `chapter_directive.scene_type` 字段（首次实现，参考用）
2. **叙事功能**：起点 / 转折 / 升级 / 揭秘 / 收束
3. **关系阶段**：陌生人 / 暧昧 / 心动 / 考验 / 真相 / 新平衡
4. **预期糖点**：本章程式糖点种类

判定顺序：章纲 > 关系阶段 > 叙事功能 > 预期糖点。

## 十种言情章型

### 1. 相遇章（Establishing Encounter）

**使用条件**：第 1 章；或男女主长期分离后的首次重逢。

**结构骨架**：
```
[开场 0-400 字]      陌生环境 + 女主处境（带读者进世界观）
[初见 400-800 字]    男主登场 + 第一次对峙/误会/不可控事件
[危机 800-1500 字]   事件发酵（女主遇险/男主暴露/共同意外）
[章末钩子 1500-2000] 留下"他们下次还会见吗"或"他/她到底是谁"
```

**节奏比例**：30% 处境 / 30% 登场 / 25% 危机 / 15% 钩子

**糖点位置**：
- 800-1200 字：第一个**微酸**（他/她做了一件让她/他不满的事）
- 1200-1500 字：第一个**微触**（救她/护她/无意肢体接触）

**典型模板句**：
- ❌ "他从未见过这样的女孩子。"
- ✅ "她低头找东西时，他看见了她的睫毛——五分钟后他才意识到自己忘了她在找什么。"

**章末钩子模板**：
- "她不知道，那个男人在她身后站了整整三分钟。"
- "他没回头。但他记下了她外套上的校徽。"

**踩坑警示**：
- ❌ 男主救女主 → 一见钟情 → 太套路
- ✅ 第一次见面有"压迫感"或"错位"，第二次见面才开始心动

### 2. 重逢章（Reunion）

**使用条件**：分手/误会/失联后首次见面。

**结构骨架**：
```
[开场 0-300 字]      环境（她/他常去的地方 / 某个公共场合）
[识别 300-800 字]    看见对方 + 心理反应（震惊/克制/装作没看见）
[表面接触 800-1400]  礼貌交谈 / 假装不认识 / 维持表面平静
[细节失控 1400-1800] 一个旧物 / 旧称呼 / 旧习惯让双方破防
[章末钩子 1800-2000] 留下"她/他怎么收场"
```

**节奏比例**：15% 识别 / 30% 表面 / 20% 失控 / 15% 钩子（加 20% 环境铺垫）

**糖点位置**：
- 1400-1800 字：**微烫**核心位置（细节失控的爆点）

**典型模板句**：
- ❌ "她没想到会再见到他。"
- ✅ "机场到达大厅的滚动屏上，她看到了他的名字——那一栏的航班，30 分钟前已经落地。"

**章末钩子模板**：
- "她想叫他。但开口的瞬间，她发现自己叫的是他三年前的昵称。"
- "他先认出了她。然后他意识到，他用的是 5 年前的告别方式。"

**踩坑警示**：
- ❌ 立刻抱头痛哭 / 一方转身就走
- ✅ 维持表面 800 字，让"细节"先失守

---

### 3. 误会章（Misunderstanding）

**使用条件**：第 11-30 章常见；信息差导致的对立。

**结构骨架**：
```
[开场 0-300 字]      触发误会的事件
[男主视角 300-1000]  男主看到的"证据"（读者已知是错的）
[女主视角 1000-1700] 女主不知道男主看见 / 正在做另一件事
[对峙 1700-1900]     两人正面冲突（克制 / 冷言冷语）
[章末钩子 1900-2000] 留一个"读者知道的真相男主不知道"
```

**节奏比例**：15% 触发 / 35% 男主视角 / 35% 女主视角 / 10% 对峙 / 5% 钩子

**糖点位置**：
- 1700-1900 字：**微酸**核心位置（对峙时他/她做了一件让她/他心痛的事）

**典型模板句**：
- ❌ "他以为她不爱他了。"
- ✅ "他以为她不爱他了。但他不知道的是，她刚放下电话——电话那头是他妈，她刚答应替他照顾他三天。"

**章末钩子模板**：
- "她把门关上。他站在门外，把准备了三天的解释咽了回去。"
- "她转身走了。她没看见他的右手——那只手里攥着三个月前她'不小心'落下的发卡。"

**踩坑警示**：
- ❌ 让读者和男主同步知道"真相"——错失上帝视角的爽感
- ✅ 真相必须让**读者先知道**

---

### 4. 心动章（First Stir）

**使用条件**：暧昧期向心动期过渡的关键章。

**结构骨架**：
```
[铺垫 0-500 字]       两人日常相处 / 共同做事
[小细节 500-900]      她/他无意间做了一件让自己意识到的事
[自我怀疑 900-1300]   她/他开始问自己"我是不是..."
[对方也动摇 1300-1700] 对方做出一个让两人关系升级的动作
[章末钩子 1700-2000]  留"下一次见面会怎样"
```

**节奏比例**：25% 铺垫 / 20% 细节 / 20% 自疑 / 25% 对方动作 / 10% 钩子

**糖点位置**：
- 500-900 字：**微烫**第一个位置（自我意识到"我好像..."的瞬间）
- 1300-1700 字：**微烫**第二个位置（对方做出动作的瞬间）

**典型模板句**：
- ❌ "她发现自己爱上了他。"
- ✅ "她发现自己已经在门口等了 20 分钟——而他说的'马上到'，意思是'还要一小时'。"

**章末钩子模板**：
- "她没敢回头。她听见自己的心跳声大到她觉得他一定听见了。"
- "他第一次叫她名字时顿了一下。她没注意。但他注意到了。"

**踩坑警示**：
- ❌ 两个人同时意识到 → 失去节奏感
- ✅ 让一个人先意识到，另一个人慢半拍（但不超过 3 章）

---

### 5. 表白章（Confession）

**使用条件**：心动确认后的关键章；通常在 30-50 章之间。

**结构骨架**：
```
[铺垫 0-400 字]        场景氛围（仪式感 / 私密空间）
[准备 400-800 字]      表白方独处 / 反复确认
[触发 800-1200 字]     一个具体事件让表白方无法再忍
[表白瞬间 1200-1600]   说出来（注意：说不出来也可以）
[对方反应 1600-1900]   不立刻答应（避免"假两难"）
[章末钩子 1900-2000]   留"她会答应吗 / 他还在等"
```

**节奏比例**：20% 氛围 / 20% 准备 / 20% 触发 / 20% 表白 / 15% 反应 / 5% 钩子

**糖点位置**：
- 1200-1600 字：**组合糖点**（表白本身就是大糖，但要靠行动不靠话）

**典型模板句**：
- ❌ "我喜欢你。从第一次见到你开始。"
- ✅ "'你今天还会来吗？'——这是他第一次用这种语气问她。她说'嗯'的时候，他整个人愣住了。"

**章末钩子模板**：
- "她没说话。她只是把他送的花放进了自己的包里——没还回去。"
- "他不知道自己是怎么走出她家的。但他记得自己说'那明天见'的时候，声音都在抖。"

**踩坑警示**：
- ❌ 表白方说完对方立刻答应 → 没有张力
- ✅ 表白方说完**对方没立刻回答**——但给读者一个暗示她会答应

---

### 6. 信任危机章（Trust Crisis）

**使用条件**：关系考验期的核心章；通常在 50-70 章。

**结构骨架**：
```
[事件触发 0-400 字]    一件背叛 / 谎言 / 隐瞒浮出水面
[记忆闪回 400-1000]    过去两人相处的细节（突然有了另一层含义）
[对峙 1000-1500]       双方对峙 / 一方崩溃 / 一方冷处理
[真相碎片 1500-1800]   一点点新的信息浮出来（不全）
[章末钩子 1800-2000]   留"他们还能回到从前吗 / 真相到底是什么"
```

**节奏比例**：20% 触发 / 30% 闪回 / 25% 对峙 / 20% 碎片 / 5% 钩子

**糖点位置**：
- 1000-1500 字：可有 **微酸**（他/她无意中做了让她/他失望的事）
- 不必有微甜——本章是情感低谷

**典型模板句**：
- ❌ "她不敢相信他会骗她。"
- ✅ "她想问他为什么不告诉她。但她发现自己想问的其实是另一个问题——'如果我早一点知道，你会改吗？'"

**章末钩子模板**：
- "他把钥匙还给她。她没收。但他放下的那一刻，她听见了钥匙碰到桌面的声音——那声音在她心里响了三年。"
- "她决定离开。但她在门口站了一分钟——那一分钟里，她在等他说一句话。他没说。"

**踩坑警示**：
- ❌ 真相一次性揭露 → 失去节奏感
- ✅ 真相分 3-5 次揭露——本章只揭 1-2 个碎片

---

### 7. 复仇章（Revenge Strike）

**使用条件**：第 71-85 章爆发期；反派长期压制后的反击。

**结构骨架**：
```
[布局 0-400 字]         主角已掌握的证据/筹码
[触发 400-800 字]       反派又作恶一次 / 公开场合的挑衅
[收集证据 800-1300]     最后一刻的补刀（盟友 / 旧敌的帮助）
[公开揭露 1300-1800]    在反派最得意的场合当众翻盘
[反派反应 1800-1950]    反派不可置信 / 试图狡辩 / 崩溃
[章末钩子 1950-2000]    留"反派下一步 / 新反派浮现"
```

**节奏比例**：20% 布局 / 20% 触发 / 25% 收集 / 25% 揭露 / 8% 反应 / 2% 钩子

**糖点位置**：
- 1300-1800 字：**组合糖点**（女主翻盘时男主必到场护她 + 公费撒糖）

**典型模板句**：
- ❌ "她的复仇终于成功了。"
- ✅ "她站起来的那一刻，他已经在门口等她了——他没帮她复仇。但他在那里。"

**章末钩子模板**：
- "她赢了。但她父亲留下的那枚戒指，从反派手里掉出来时，她发现那戒指上刻着一个名字——是她母亲的名字。"
- "反派被带走了。可她没笑——她在想，下一个来的人会是谁。"

**踩坑警示**：
- ❌ 反派翻车靠男主一句话
- ✅ 女主必须先立住自己——男主只是兜底

---

### 8. 反派翻车章（Villain Downfall）

**使用条件**：配合"复仇章"使用，但侧重反派而非女主。

**结构骨架**：
```
[反派得意 0-400 字]     反派处于最得意的状态
[女主设局 400-1000]     女主 / 男主布置的陷阱（读者已知）
[反派入局 1000-1500]    反派一步步掉进陷阱
[翻车瞬间 1500-1800]    反派被当众揭穿 / 失去最重要的东西
[反派落幕 1800-1950]    反派的最后一刻（保留尊严 or 崩溃）
[章末钩子 1950-2000]    留"她/他怎么看待这场胜利"
```

**节奏比例**：20% 得意 / 30% 设局 / 25% 入局 / 15% 翻车 / 8% 落幕 / 2% 钩子

**糖点位置**：
- 1500-1800 字：**微烫**（反派翻车时男主/女主的某个动作——如他伸手扶她）

**典型模板句**：
- ❌ "反派跪地求饶。"
- ✅ "反派被带走的瞬间，她看见反派口袋掉出来的东西——是反派三年前写给她女儿的一封信。"

**章末钩子模板**：
- "她看着反派离开的方向。她没笑。她想起反派第一次害她时，她才 16 岁。"
- "反派输了。但她知道反派身后还有别人。"

**踩坑警示**：
- ❌ 反派"跪地求饶"——违反 playbook §五·5.8
- ✅ 给反派一个**有尊严的落幕**（她可以输，但不能被打成小人）

### 9. 真相大白章（Truth Reveal）

**使用条件**：身份 / 替身 / 前世今生 / 血脉揭秘的核心章。

**结构骨架**：
```
[线索汇集 0-500 字]     之前各章留下的碎片在此汇集
[触发事件 500-1000]     一件事让真相必须现在揭露
[揭露过程 1000-1700]    真相一件件浮出（不是一次性）
[情感冲击 1700-1900]    男女主各自的反应（先震惊后消化）
[章末钩子 1900-2000]    留"他们要怎么处理这件事 / 关系会怎样"
```

**节奏比例**：25% 线索 / 25% 触发 / 35% 揭露 / 10% 反应 / 5% 钩子

**糖点位置**：
- 1700-1900 字：**微烫**（真相揭露后他/她做出一个让对方心安的承诺）

**典型模板句**：
- ❌ "原来她才是真正的千金。"
- ✅ "'所以……'她看了他一眼，'你早就知道了？'他点头。她又问：'为什么不告诉我？'他答：'因为你是你，跟你是谁没关系。'"

**章末钩子模板**：
- "她看着手里的旧照片。她想起他第一次见她时看她的眼神——原来他从一开始就知道。"
- "真相揭开了。但她面前摆着两个选择——回家，或者留下来陪他。"

**踩坑警示**：
- ❌ 真相一次性揭露 + 双方立刻接受 → 没有情绪张力
- ✅ 真相分 3-5 次揭露 + 双方需要时间消化

---

### 10. 大婚章（Wedding / Union）

**使用条件**：第 86-100 章新平衡期；卷末或全本收束章。

**结构骨架**：
```
[准备 0-500 字]          婚礼/确认关系前的最后准备
[到场 500-900 字]        双方亲友 / 反派的最后一次出没（被化解）
[仪式核心 900-1500]      婚礼进行 / 承诺交换
[糖点爆发 1500-1800]     这一刻的极致糖（多年铺成的兑现）
[新期待 1800-2000]       留"接下来他们的生活会怎样 / 下一卷伏笔"
```

**节奏比例**：25% 准备 / 20% 到场 / 30% 仪式 / 15% 糖点 / 10% 新期待

**糖点位置**：
- 900-1500 字：**组合糖点**（婚礼本身）+ **微烫**（他对她的某个动作）
- 1500-1800 字：**里程碑糖点**（多年铺垫的集中兑现）

**典型模板句**：
- ❌ "她终于嫁给了爱情。"
- ✅ "她走过红毯时，他在另一头等她——他没笑，但他眼睛红了。她第一次见到他哭。"

**章末钩子模板**：
- "他们交换戒指时，他低声说了句只有她听见的话。她没告诉任何人——但她的表情说明了一切。"
- "婚礼结束。但在她回家的路上，他停下车，第一次主动吻了她——那个吻里有一百章的重量。"

**踩坑警示**：
- ❌ 把大婚写成"从此幸福地生活在一起" → 失去钩子
- ✅ 留一个**下一卷的暗示**（她身体异样 / 他收到神秘来信 / 新的家族出现）

## 十一、短章 / 过渡章模板（<1500 字）

```
[开场 0-300 字]      锚定本章叙事功能（回忆 / 时间跳跃 / 信息补全）
[核心 300-1000]      一件事 + 一个细节 + 一个钩子
[章末 1000-1500]     一句情感性钩子 + 一个未解的小事
```

过渡章**必须**包含至少 1 个微触或微甜——读者最讨厌"过渡章没感情戏"。

---

## 十二、AI 执行指令

1. **每章起草前必判定章型**：context-agent 必须在任务书第 1 段标注本章属 10 种章型中的哪一种。
2. **结构骨架必须执行**：本章节模板的"结构骨架"段落是硬性章节节奏——不允许改比例超过 ±10%。
3. **糖点位置强制**：每个章型指定的"糖点位置"是必放位置，不允许空缺。
4. **章末钩子必须使用模板句**：禁止自己造钩子——模板句经过验证。
5. **踩坑警示必读**：写章前 context-agent 必须复读本章节的"踩坑警示"。
6. **跨章审查联动**：cross-chapter-reviewer 检查时，可参照本文件判定章节结构是否完整。
7. **新章型判定规则**：如果章纲不属于以上 10 种，请回到通用 strand-weave-pattern.md；言情长篇 90% 章节都落在以上 10 种内。

</instructions>
