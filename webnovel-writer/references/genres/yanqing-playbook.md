## 一、六种言情专属爽点模式

通用爽点（装逼打脸/扮猪吃虎/越级反杀等）适用于男主升级，言情则以**情感兑现**为主。言情读者爽的不是"打倒敌人"，是"情感悬念被精准满足"。

### 1. 暗涌式心动（Slow Burn Reward）
```
长线铺垫（30-50章暧昧/拉扯）→ 一个具体动作兑现 → 心动瞬间爆发
```
**适用**：现言、古言、青春甜宠
**示例**：男主前 50 章一直"克制护短"，第 51 章在所有人面前拉开椅子让她坐下——全场沉默，读者尖叫。
**关键**：兑现动作必须**够小**（不是告白），**够准**（她最在意的细节他记得），**够公开**（让围观者见证）。

### 2. 反差式沦陷（Iceberg Melt）
```
男主/女主持续高冷 → 一次失控露出破绽 → 强势方先低头
```
**适用**：豪门总裁、宫斗宅斗、师徒文
**示例**：男主表面冷淡 30 章，第 31 章因女主受伤，第一次握住她的手且忘了松开。
**关键**：必须有一次"反差点"——读者期待已久的那个破绽。铺垫越长，反差越大，爽感越强。

### 3. 误会式心疼（Anguish Boost）
```
男女主因信息差误会 → 读者比任何人都先知道真相 → 一起心疼
```
**适用**：狗血言情、替身文、古言虐恋
**示例**：女主以为男主不爱她，读者已知男主为她挡了致命一刀。读者被迫"看着误解发生"，越看越上头。
**关键**：信息差必须在读者侧呈现，让读者**有上帝视角的优越感**。

### 4. 公费式撒糖（Public Sweetness）
```
两人维持上下级/敌对/误会关系 → 公开场合因意外暴露亲密 → 围观者震惊
```
**适用**：古言、宫斗、豪门、校园甜宠
**示例**：女上司与男下属会议室吵架，被撞见他在办公室帮她吹头发。
**关键**：必须有一个**被迫公开的场景**（酒会/电梯/会议室/雨中共伞）。日常糖不算公费。

### 5. 身份式碾压（Status Reversal）
```
女主一直被低估（灰姑娘/庶女/实习生）→ 身份揭晓 → 全场反转
```
**适用**：替身文、宫斗宅斗、豪门总裁
**示例**：庶女回府，全家以为她好欺负；宴会上皇家令牌一掏，嫡姐跪地。
**关键**：身份反转必须配合"一直护着她的男主"的反差——他早知道，等她自己揭晓。这才有双重爽感。

### 6. 深情式回响（Echo Payoff）
```
前期埋一句承诺/一句话/一件小事 → 几十章后由另一方精准兑现
```
**适用**：所有言情题材
**示例**：第 3 章女主说"我想要一个家"，第 80 章男主在废墟中对她说"我给你"。
**关键**：兑现方必须是**当时那个听不见的人**——他要回去告诉当年的她"我听到了"。

## 二、六种言情专属反转套路

通用反转见 `bridge-pattern.csv`（TR 系列），本节只讲言情特化。

### R1. 真假千金 / 替身白月光
**结构**：被替换身份 → 真相揭晓 → 女主身世/价值被重新定义。
**反套路变种**：不要让"真千金"赢；让女主（假千金）凭本事立足，反派真千金反而无德。
**毒点**：女主靠男主撑腰才能赢 → ✅ 让女主自己先立住，男主只是兜底。

### R2. 重生/前世今生
**结构**：女主带着前世记忆重生 → 改写关键悲剧 → 男主后来察觉她"不一样了"。
**反套路变种**：不要让她一重生就秒天秒地——给 3-5 章"重新建立信任"的过渡期，读者才能看到她的成长。
**毒点**：重生后直接吊打原女主 → ✅ 让男主先爱上"重生后的她"，再揭真相。

### R3. 失忆/认错人
**结构**：A 救了人/付出全部 → 被当成 B → 真相对峙那一刻爆发。
**反套路变种**：失忆不等于降智——她失忆后的"本能反应"才是真相的伏笔。
**毒点**：靠"血型鉴定/玉佩"机械揭晓 → ✅ 让情感细节先泄露（她习惯性偏爱他不知的事）。

### R4. 复仇/反派翻车
**结构**：反派长期压制女主 → 女主借势让反派自毁。
**反套路变种**：反派不必坐牢——让她**失去她最在意的东西**比坐牢更疼。
**毒点**：反派被男主一句话击溃 → ✅ 让女主主导反击，男主只在最后配合。

### R5. 错位告白/反向告白
**结构**：男主以为女主不爱自己 → 实际她已为他做了所有 → 表白那一刻反转。
**反套路变种**：让女主先知道但不敢说，男主最后才懂——读者先心疼再爽。
**毒点**：告白靠"酒后乱性"或"误会撞破" → ✅ 让双方各自压抑再相遇。

### R6. 破镜重圆/久别重逢
**结构**：旧伤未愈 + 误会未解 + 身份变化 → 表面克制 + 细节失控。
**反套路变种**：见面前 5 章不要让他们单独相处——让他们各自克制 5 章，第 6 章才崩。
**毒点**：重逢立刻抱头痛哭 → ✅ 让两人各自维持体面，靠一句旧称呼或一件旧物撬开情绪。

## 三、糖点节奏（每章的"情感微兑现"清单）

言情读者最挑剔的就是**糖点密度**。通用爽点指南只有"爽点密度建议"，言情需要细化到**糖点**。

### 3.1 糖点类型（4 种）

| 类型 | 描述 | 适用阶段 |
|------|------|----------|
| **微触** | 不经意的肢体接触（递水/拉袖/扶腰） | 全程 |
| **微甜** | 不直白的宠溺（帮她挡酒/记得她过敏/突然出现） | 暧昧期/拉扯期 |
| **微酸** | 暧昧误会/吃醋（看见她和别的男人说话/发现她的旧情史） | 暧昧期/恋爱初期 |
| **微烫** | 心动瞬间（他突然靠近/她红了耳尖/两人同时沉默） | 高潮前/告白前 |

### 3.2 糖点强制密度（言情变体，替换通用规则的"爽点密度"）

| 周期 | 要求 | 不达标后果 |
|------|------|------------|
| 逐章 | ≥1 个微触或微甜 | 读者觉得"这章没感情戏" |
| 每 3 章 | ≥1 个微烫或微酸 | 读者觉得"暧昧太慢了/腻了" |
| 每 10-15 章 | ≥1 个组合糖点（≥2 种叠加） | 读者觉得"感情线没进展" |
| 每 30-50 章 | ≥1 个里程碑糖点（公开/表白/确认关系） | 读者弃书 |

### 3.3 微烫糖点模板（10 种可直接套用）

1. **"她/他忘了松手"**：握着她/他的手，停了三秒才意识到该放开。
2. **"异口同声"**：两人同时说出同一句话，对视一秒后各自别过头。
3. **"回护本能"**：危险/尴尬发生时，他/她下意识挡在前面。
4. **"读出潜台词"**：她/他听见她说"没事"，立刻察觉她不开心，并准确指出原因。
5. **"失神称呼"**：他在同事面前叫她小名/昵称，意识到后停顿，旁人起哄。
6. **"吃醋失控"**：他/她一直冷脸，看见她和别的异性说话，握住她手腕拉走。
7. **"深夜独白"**：以为对方睡着时说出真心话，对方其实没睡。
8. **"礼物盲盒"**：她/他随手送的小东西，恰好是她/他一直想要的。
9. **"公共场合克制"**：电梯/车里狭小空间，两人贴近，强迫自己冷静。
10. **"反向霸道"**：平时温柔的她/他，忽然用不容拒绝的语气保护对方。

### 3.4 微烫糖点禁忌

- ❌ 重复使用同一种糖点超过 3 次
- ❌ 糖点前没有铺垫（突然温柔显得"工具人"）
- ❌ 糖点后立刻推进冲突（让糖点变成"假高潮"）
- ❌ 用旁白宣告感情（"她知道他爱她"）——必须用行为/生理暗示

## 四、情感节奏曲线（言情版）

通用题材的节奏曲线见 `strand-weave-pattern.md`，言情需要叠加情感曲线。

### 4.1 单章情感弧（5 段式）

```
开篇钩子（陌生/冲突/疏离）→
  推进（一件具体事件推进关系）→
    心动点（微烫糖点或微酸吃醋）→
      紧张/考验（信息差/外部压力）→
        章末钩子（留下期待/留一个未完的动作/未说完的话）
```

### 4.2 卷级情感弧（4 段式）

```
[铺垫卷 5-10 章]：建立关系 + 制造信息差 + 第一次心动
[拉扯卷 10-15 章]：外部阻力 + 双向误会 + 多次微烫/微酸
[爆发卷 5-10 章]：真相揭露 + 公开 + 表白或确认关系
[过渡卷 3-5 章]：甜蜜日常 + 新的外部威胁（为下一卷埋伏笔）
```

### 4.3 100 章长篇情感节奏模板

```
第 1-10 章：建立期（男女主相遇 → 第一次冲突 → 第一次心动）
第 11-30 章：拉扯期（暧昧升温 + 外部压力 + 反复拉扯）
第 31-50 章：确认期（告白/确认关系 + 第一次大考验）
第 51-70 章：考验期（外力/误会/失忆等大冲突 + 感情经受考验）
第 71-85 章：爆发期（真相大白 + 反派翻车 + 感情公开/升华）
第 86-100 章：新平衡期（甜蜜日常 + 新势力/新地图伏笔）
```

### 4.4 心动点分布（100 章模板）

| 章节区间 | 微烫心动 | 微酸吃醋 | 公开/表白 |
|----------|----------|----------|-----------|
| 1-10 | 1 | 0 | 0 |
| 11-30 | 3-4 | 4-5 | 0 |
| 31-50 | 2-3 | 2 | 1（确认关系） |
| 51-70 | 2 | 2 | 0 |
| 71-85 | 1-2 | 1 | 1（升华/公开） |
| 86-100 | 2-3 | 1 | 0 |
| 合计 | 11-15 | 10-11 | 2 |

## 五、情感真实度协议（言情防 AI 味专项）

言情读者最敏感的就是"假"。以下 5 条强制规则：

### 5.1 不直白
- ❌ "她感到自己心跳加速，脸颊发烫。"
- ✅ "她把脸别过去，却忘了自己手里还攥着他的袖子。"
- ❌ "他知道她一直在他身边默默支持。"
- ✅ 他每次回头，她都在。不说话，就只是在那里。

### 5.2 不悬浮
- ❌ "他对她的感情如潮水般汹涌。"
- ✅ "他压低声音，那三个字被他咬碎在嘴边，最后只剩下一句——'别走。'"
- ❌ "她很感动。"
- ✅ "她没说话。只是把那张纸条叠了三折，夹进笔记本最后一页。"

### 5.3 不工具人
- 男主不能只是"深情机器"——他必须有自己的事业、伤痛、家人、习惯，这些与女主故事线交织。
- 女主不能只是"被宠的公主"——她必须有独立目标、独立决策能力、独立的人际圈。

### 5.4 不完美主义
- 女主不一定要"完美受害者"——可以有小脾气、可以犯错、可以有过错方。
- 男主不一定要"全能深情"——可以笨拙、可以犹豫、可以有没说出口的话。
- 真实感来自**缺陷共存**。

### 5.5 不滥用巧合
- 每 3 次"命运般相遇"必须有一次是"刻意制造"——读者需要看到"双方都在主动选择"。
- 反派/男二/女二的介入必须是**有动机的**，不是"剧情需要"。

### 5.6 不悬空台词
言情最容易崩的是"为了气氛而气氛"的对话——读者读完觉得"这两个字没说出来对剧情也没影响"。

- ❌ "你要好好的。"（万能关怀，无角色特色）
- ✅ "明天记得带伞。天气预报说下午有雨。"（关心的具体动作）
- ❌ "我等你回来。"（空洞承诺）
- ✅ "冰箱里有我昨晚包的饺子，饿了就自己煮。"（用行动承诺）

每句对白必须能回答："如果删掉这句，剧情或人物会不会变？"——如果是"不会"，就删掉或重写。

### 5.7 不靠巧合恋爱
言情最容易让读者出戏的是"莫名其妙就爱上了"——本章还互相敌视，下章突然就心动。

- ❌ 撞车 / 突然摔倒被接住 → 就此爱上（无前因后果）
- ✅ 撞车前已多次偶遇 / 摔倒前她帮他挡过雨 → 一撞是导火索
- ❌ 退婚/失忆后男方突然"悔不当初"爱上女主 → 无任何转变铺垫
- ✅ 退婚前已有 ≥3 次他主动找她的细节；失忆后他随身携带她的旧物

爱上之前必须有以下至少 2 项铺垫：
1. 对方帮过她（具体事件，非"照顾"）
2. 对方有某个她**独有的认可**（一个习惯、一个观点、一句话）
3. 对方在她最脆弱时在场
4. 对方与她有 ≥3 次对话，且至少 1 次触及她内心

### 5.8 不忽视反派动机
反派女二 / 男二如果只是"嫉妒女主所以要害她"——读者立刻弃书。每个反派必须有：

1. **可被理解的动机**：她不是在作恶，她是在追求某种她认为正当的东西
2. **可被欣赏的能力**：她在某些维度比女主更强（让读者不讨厌她）
3. **可被同情的过去**：她走到今天，一定有她的"不得已"
4. **可被尊重的退场**：反派翻车时不要让她"跪地求饶"——给她一个有尊严的结局

推荐类型：
- 被家族牺牲的妹妹
- 与男主有过真实过去的青梅
- 为了保护重要之人不得不与女主为敌的姐妹
- 真心爱男主但不被男主回应的深情者（她不是坏人）

### 5.9 不滥用巧合反转
言情反转的爽感来自"读者期待已久"——如果反转靠"突然出现的天降神兵"、"恰好听到的对话"、"刚好路过的证人"，读者会觉得被敷衍。

❌ 巧合反转的反面教材：
- 女主被陷害时，男主"恰好"出现
- 反派阴谋被揭穿时，关键证据"刚好"被捡到
- 真相揭露时，女主"突然"记起前世记忆

✅ 替代方案：
- 男主出现是因为女主之前留给他的线索（伏笔回收）
- 关键证据是反派自己露出马脚（人设一致性）
- 真相揭露时女主通过 5 章的观察逐渐拼图

每个巧合反转都必须有 ≥1 章前的铺垫。铺垫未达标的反转，会被 cross-chapter-reviewer 标记 `severity=medium`。

## 六、AI 执行指令（言情变体）

1. **每章起草前必查**：
   - 本章预计属于哪个情感节奏区间（4.3 表）
   - 本章应放哪种糖点（3.1 表 + 3.3 模板）
   - 本章男女主应推进哪一种情感关系维度（信任/亲密/承诺/激情/安全感，任一即可）

2. **每章起草后必查**：
   - 至少 1 个微触或微甜
   - 章末钩子必须是**情感性钩子**（未说完的话/未做完的动作/未揭开的真相），不是事件性钩子
   - 男女主对话中至少 1 次"潜台词对话"（说 A 实际表达 B）

3. **每 3 章触发一次糖点密度审计**：
   - 最近 3 章是否每章都有 ≥1 微触/微甜
   - 是否有 ≥1 微烫或微酸
   - 不达标 → 报告交 cross-chapter-reviewer（severity=medium，blocking=false）

4. **每 10 章触发一次关系进度审计**：
   - 关系阶段是否与"100 章模板"匹配
   - 反派/男二/女二是否缺席超过 5 章
   - 不达标 → 报告交 cross-chapter-reviewer（severity=medium）

5. **言情专属 strand 配比**（与通用 `strand-weave-pattern.md` 不同）：
   - Quest：30-40%（言情也有主线，但不是核心）
   - Fire：**45-55%**（感情线是绝对主线，优先于主线）
   - Constellation：15-20%（世界观/反派为感情戏服务）
   - Quest 不连续超过 3 章必须切到 Fire 或 Fire-Constellation 融合段

</instructions>
