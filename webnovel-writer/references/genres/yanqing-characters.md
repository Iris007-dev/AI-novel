## 一、男主 6 型

### M1 高冷霸总
- **特征**：外冷内热，不善言辞；用行动表达感情；社交场合永远得体；极少情绪外露。
- **核心张力**：他的"冷"和"热"反差越大越有戏；一句话里 99% 是公事，1% 是关心。
- **关系路径**：陌生人 → 误会/敌视 → 被她的某个细节打动 → 用行动代替表白 → 情感失控的某个瞬间（最爽）。
- **适配女主**：聪慧冷静 / 坚韧独立 / 反差魅力。
- **糖点方向**：少言多行；一个动作胜过一个情话；公开场合罕见的柔软。
- **踩坑**：❌ 高冷 = 不会犯错——他必须有 ≥2 个让女主心动的弱点。

### M2 温柔守护
- **特征**：永远在她身边；不强迫；用耐心和细节感化；不会主动表白但会主动做事。
- **核心张力**：他的"守"和"求"的平衡——他愿意等，但他等的代价是什么？
- **关系路径**：青梅/同事/邻居 → 一直陪着她 → 女主遇到麻烦 → 他默默解决 → 女主发现真相 → 关系升级。
- **适配女主**：坚韧独立 / 反差魅力 / 救赎型。
- **糖点方向**：细节糖（帮她挡酒 / 记得她过敏 / 她加班他默默送饭）；沉默陪伴。
- **踩坑**：❌ 温柔 = 无底线——他必须有他自己的底线和拒绝。

### M3 痞气幽默
- **特征**：表面玩世不恭；嘴上不饶人；行动上靠谱；总能让她笑。
- **核心张力**：痞气与深情的反差；他越不正经，真情流露时越动人。
- **关系路径**：冤家/损友 → 互相拆台 → 她出事他第一个到 → 他暴露真面目 → 她发现他从一开始就在护她。
- **适配女主**：聪慧冷静 / 白月光 / 反差魅力。
- **糖点方向**：嘴炮糖（互怼但有深意）；反差糖（他表面痞，私下认真）。
- **踩坑**：❌ 痞气 = 不认真——他对她必须有认真的瞬间。

### M4 病娇偏执
- **特征**：爱到极致；情感浓烈；可能极端占有；情感强度 > 理性。
- **核心张力**：他的爱是否"过度"——他以为的保护，可能是她的囚禁。
- **关系路径**：陌生人 / 救命恩人 / 长期暗恋 → 他开始介入她的生活 → 女主发现他对她的占有 → 信任危机 → 他让步或她逃离 → 最终他找到平衡。
- **适配女主**：坚韧独立 / 聪慧冷静 / 反差魅力（绝不推荐"圣母"女主配病娇）。
- **糖点方向**：极端糖（他为了她做什么都可以）；张力糖（他想占有但又舍不得）。
- **踩坑**：❌ 病娇 = 完美情人——他必须有真正的缺陷，且必须有"让步"或"自省"时刻。

### M5 权谋深沉
- **特征**：心思缜密；很少展露真实情感；布局长远；情感是"大局"的一部分。
- **核心张力**：他的"算"和"情"——他对她的感情，是算计还是真心？
- **关系路径**：政治/家族/商业合作 → 互相试探 → 他发现她懂他 → 两人联手 → 真相大白：他对她的算计里有真心。
- **适配女主**：聪慧冷静 / 双强 / 救赎型。
- **糖点方向**：信任糖（他给她看真实的一面）；反向糖（她帮他卸下面具）。
- **踩坑**：❌ 权谋 = 没有真心——他必须有 1-2 个让他失控的瞬间。

### M6 暗涌隐忍
- **特征**：爱而不说；默默做；承担所有压力；让她看不见他背后的代价。
- **核心张力**：他的"不让她知道"——这种牺牲是伟大还是压抑？
- **关系路径**：青梅 / 同事 / 长期暗恋 → 她不知道他为她做了什么 → 真相揭露 → 她追他 → 他终于松手。
- **适配女主**：坚韧独立 / 反差魅力 / 救赎型。
- **糖点方向**：知情糖（读者知道但女主不知道）；反应糖（他听到她名字时手指微动）。
- **踩坑**：❌ 隐忍 = 透明——他必须有"被看见"的时刻。

## 二、女主 6 型

### F1 坚韧独立
- **特征**：靠自己；不依赖男主；有明确的人生目标；遇到困难不轻易崩溃。
- **核心张力**：她的"独立"会不会成为感情的阻力——她能不能接受"示弱"？
- **关系路径**：从不依赖 → 不愿欠他 → 被他的某个细节打动 → 学习接受帮助 → 双向奔赴。
- **适配男主**：温柔守护 / 高冷霸总 / 暗涌隐忍。
- **糖点方向**：反差糖（她独立但在他面前偶然流露脆弱）；成长糖（她开始信任）。
- **踩坑**：❌ 独立 = 不需要爱——她必须有"需要"的时刻。

### F2 聪慧冷静
- **特征**：聪明理性；看透人心；不轻易动情；有自己的判断。
- **核心张力**：她的"理性"——她会不会因为"算清楚"而错过爱？
- **关系路径**：分析他 → 发现他不是她想的那种人 → 被某个非理性瞬间击溃 → 接受感情。
- **适配男主**：权谋深沉 / 痞气幽默 / 高冷霸总。
- **糖点方向**：失态糖（她第一次为他失控）；反差糖（她冷静分析的尽头是他）。
- **踩坑**：❌ 聪慧 = 无情——她必须有"感性"的一面。

### F3 白月光
- **特征**：温柔美好；不主动攻击；自身有魅力但不自知；让男主愿意守护。
- **核心张力**：她的"温柔"会不会被利用——她能否看清恶人？
- **关系路径**：天真 → 受挫 → 学会分辨 → 与男主并肩。
- **适配男主**：权谋深沉 / 病娇偏执 / 暗涌隐忍。
- **糖点方向**：治愈糖（她的存在让他卸下防御）；守护糖（他愿意为她破例）。
- **踩坑**：❌ 白月光 = 傻白甜——她必须有成长弧线。

### F4 反差魅力
- **特征**：表面 A 实际 B；多面性；让读者/男主不断有惊喜。
- **核心张力**：她的"真面目"——读者/男主何时看到她真正的样子？
- **关系路径**：看见表面 → 看见真相 → 看见她更深的一面。
- **适配男主**：痞气幽默 / 高冷霸总 / 暗涌隐忍。
- **糖点方向**：反差糖（她外表冷淡内心柔软）；揭示糖（她原来是另一面）。
- **踩坑**：❌ 反差 = 没有核心——她的反差必须有一致的人格核心。

### F5 救赎型
- **特征**：她自己有伤痛；通过被男主治愈/治愈男主完成成长；情感浓度高。
- **核心张力**：她的"伤痛"和"治愈"——她愿不愿意被治愈？她能不能治愈他？
- **关系路径**：各自的伤 → 偶然相遇 → 互相成为对方的光 → 双向救赎。
- **适配男主**：病娇偏执 / 暗涌隐忍 / 高冷霸总。
- **糖点方向**：治愈糖（她让他愿意开口）；被治愈糖（他让她不再害怕）。
- **踩坑**：❌ 救赎 = 只靠男主——她必须有自己的自救部分。

### F6 双强
- **特征**：在某个维度与男主势均力敌；不靠男主也能解决问题；彼此是对手也是伴侣。
- **核心张力**：他们的"强"如何并存——他们会不会互相不服？
- **关系路径**：对手 → 互相承认 → 并肩 → 平等的伙伴关系。
- **适配男主**：权谋深沉 / 痞气幽默 / 高冷霸总。
- **糖点方向**：竞争糖（互相激将）；并立糖（他们站在同等位置）。
- **踩坑**：❌ 双强 = 不需要感情——她必须有"需要他"的时刻。

## 三、36 组合矩阵

> **推荐度** ★★★★★ = 经典爆款组合；★★★ = 稳妥；★ = 高风险高回报。

### 推荐组合 Top 5

1. **F1 坚韧 × M6 暗涌**（★★★★★）：经典中的经典。她独立，他守护；她以为不需要他，他从不打扰；真相揭露那一刻最动人。
2. **F2 聪慧 × M1 高冷**（★★★★★）：豪门 / 现言最稳组合。棋逢对手，互相算计后真心。
3. **F2 聪慧 × M3 痞气**（★★★★★）：轻松爆款。她太正经，他太痞气；反差最好笑。
4. **F4 反差 × M3 痞气**（★★★★★）：校园 / 现言甜宠爆款。两人都是"装着装着就装了 N 年"。
5. **F5 救赎 × M4 病娇**（★★★★★）：虐恋爆款。两人都有伤口，互相舔伤口。

### 高风险组合（写作难度高，需谨慎）

1. **F2 聪慧 × M4 病娇**：他以为她算得清，她以为他还能救——读者全程揪心。
2. **F6 双强 × M2 温柔**：两人都有自己主张，温柔的男主容易变成"工具人"，需要给男主独立的人格。
3. **F6 双强 × M6 暗涌**：两个都在忍，谁都不肯先开口——需要写出"彼此猜到对方也在忍"的瞬间。

## 六、关系阶段与糖点映射

### 阶段 1：陌生人/敌视（第 1-10 章）
- 核心糖点：**误会糖**（他/她做的某事被对方误解 → 真相揭露后反差）
- 禁用糖点：深情的、承诺的、亲密的

### 阶段 2：暧昧拉扯（第 11-30 章）
- 核心糖点：**暗涌糖**（他/她开始有意识地接近对方，但不明说）
- 推荐密度：每 3 章 1 个微烫

### 阶段 3：心动确认（第 31-50 章）
- 核心糖点：**确认糖**（他/她明确意识到自己的感情）
- 章末钩子必须是情感性钩子

### 阶段 4：大考验（第 51-70 章）
- 核心糖点：**坚持糖**（两人面对外部压力仍坚持）
- 推荐反派出场频次：每 5 章 1 次

### 阶段 5：真相大白 / 关系公开（第 71-85 章）
- 核心糖点：**组合糖点**（≥2 种叠加）
- 章末钩子常是"他们终于可以 XX"——读者期待已久的画面

### 阶段 6：新平衡（第 86-100 章）
- 核心糖点：**日常糖**（他们在一起的样子）
- 埋伏笔：下一卷的新反派/新危机

## 七、AI 执行指令

1. **init 阶段**：根据题材与故事氛围推荐 3-5 个高匹配度人设组合，每个组合给一句话说明为什么适配。
2. **write 阶段 Step 1**：context-agent 加载本文件后，必须在任务书第 3 段（"这章的人物"）标注：
   - 男主类型（M1-M6）
   - 女主类型（F1-F6）
   - 当前关系阶段（陌生人/暧昧/心动/考验/真相/新平衡）
   - 本章应聚焦的糖点方向
3. **write 阶段 Step 3.5**：cross-chapter-reviewer 检查糖点时，必须按"人设组合表"判定——M1 男主就少说话多行动；F2 女主就理性思考多，但允许本章有失态瞬间。
4. **plan 阶段**：根据选定人设组合，规划卷纲必须包含各阶段的"糖点聚焦映射"，不可缺。
