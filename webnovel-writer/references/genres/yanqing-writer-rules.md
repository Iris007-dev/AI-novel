## 一、字数与节奏硬指标

### 1.1 字数下限（按章型分级）

| 章型 | 默认字数下限 | 字数下限例外 |
|------|------------|-------------|
| 相遇章 | 2000 | 无 |
| 重逢章 | 2000 | 无 |
| 误会章 | 2000 | 短章可 1500（必须有 ≥1 微酸） |
| 心动章 | 2000 | 无 |
| 表白章 | 2000 | 无 |
| 信任危机章 | 2200 | 无 |
| 复仇章 | 2000 | 无 |
| 反派翻车章 | 2000 | 无 |
| 真相大白章 | 2500 | 无 |
| 大婚章 | 2500 | 无 |
| 过渡章 | 1500 | 必须有 ≥1 微触/微甜 |

低于字数下限的章节，**自动标 `reviewer.blocking=true`**，原因：长度不够时糖点和情感密度无法展开。

### 1.2 节奏变化密度（每章必查）

```
每 500 字至少 1 次节奏变化（4 选 1）：
- 短句爆发（5 字以内的句子连续 ≥2 句）
- 对话插入（≥3 句对话）
- 场景切换（地点或时间标记变化）
- 感官细节（视觉/听觉/触觉/嗅觉/味觉中的具体描写）
```

节奏变化不足 = reader 感到"读起来累"，自动标 `severity=medium`。

### 1.3 段落长度控制

```
单段不超过 200 字。
对话必须独立成段（每段一句对话，禁止把多句对话挤在同段）。
场景描写段落不超过 150 字（动作密集型战斗除外）。
```

## 二、对话硬指标

### 2.1 对话占比

```
单章对话字数占总字数比例：35-45%
- < 30%：读者觉得"剧情太干"
- > 50%：读者觉得"全是嘴炮"
```

### 2.2 男女主对话要求

```
1. 至少 1 次潜台词对话（说 A 实际表达 B）
   - 例："你今天穿得真好看"（实际意思是"我想你"）
   - 例："天气真冷"（实际意思是"我等你等到现在"）

2. 至少 1 次对话中带意图冲突（试探 / 回避 / 施压 / 诱导）
   - 例：她问他"明天有空吗"，他说"应该吧"——她知道他明天的安排，但她没直说

3. 不允许连续 3 句以上的纯信息传递对话
```

### 2.3 反派对话要求

```
1. 反派必须有自己的语言风格（与男女主区分）
2. 反派至少 1 次让读者觉得"她其实有道理"的对话
3. 反派翻车时不允许"跪地求饶"——必须保留尊严（参见 playbook §五·5.8）
```

## 三、糖点硬指标

### 3.1 单章糖点下限（按章型）

| 章型 | 微触 | 微甜 | 微酸 | 微烫 |
|------|------|------|------|------|
| 相遇章 | ≥1 | ≥0 | ≥1 | ≥0 |
| 重逢章 | ≥1 | ≥0 | ≥0 | ≥1 |
| 误会章 | ≥0 | ≥0 | ≥1 | ≥0 |
| 心动章 | ≥1 | ≥0 | ≥0 | ≥2 |
| 表白章 | ≥1 | ≥1 | ≥0 | ≥1 |
| 信任危机章 | ≥0 | ≥0 | ≥1 | ≥0 |
| 复仇章 | ≥0 | ≥1 | ≥0 | ≥1 |
| 反派翻车章 | ≥0 | ≥1 | ≥0 | ≥1 |
| 真相大白章 | ≥0 | ≥1 | ≥0 | ≥1 |
| 大婚章 | ≥1 | ≥1 | ≥0 | ≥2 |
| 过渡章 | ≥1 | ≥0 | ≥0 | ≥0 |

注：糖点可在不同位置重叠（如"心动章 ≥2 微烫"中一个在 500-900 一个在 1300-1700）。

### 3.2 糖点连续监测（cross-chapter-reviewer 执行）

```
连续 3 章每章糖点 < 章节要求 → 标 severity=medium, blocking=false
连续 5 章每章糖点 < 章节要求 → 标 severity=high, blocking=true
```

### 3.3 糖点新颖性（避免重复套路）

```
同一类型糖点连续 3 章重复使用 → 标 severity=low, blocking=false
（不同章型不同类型糖点的轮换，详见 chapter-templates.md 各章型糖点位置）
```

## 四、章末钩子硬指标

### 4.1 钩子类型强制要求

```
言情长篇 100% 章末钩子必须是情感性钩子：
- ✅ 未说完的话（"她想说...但最后只说了..."）
- ✅ 未做完的动作（"他的手抬到一半又放下"）
- ✅ 未揭开的真相（"她不知道，他口袋里有一封..."）
- ✅ 未实现的承诺（"他说等这件事结束，有话对她说"）

❌ 禁止使用事件性钩子：
- "第二天，她发现他不见了"
- "三日后，真相大白"
- "敌人终于来了"
```

### 4.2 钩子字数位置

```
钩子必须在最后 100-300 字内（不是后 80-150 字那么死）
钩子必须是最后 1 个完整段落或最后 2 个对话
钩子之后禁止加任何解释性旁白
```

### 4.3 钩子新颖性（同 §3.3）

```
同一钩子模板连续 5 章重复 → 标 severity=low, blocking=false
```

## 五、情感真实性硬指标（言情专属）

### 5.1 禁止直白情绪标签

```
❌ "她感到心跳加速"
❌ "他很感动"
❌ "她觉得眼眶湿润了"
❌ "他对她有强烈的感情"

✅ 改用：行为 / 生理 / 物体 / 时间暗示
- "她把脸别过去，却忘了自己手里还攥着他的袖子"
- "他压低声音，那三个字被他咬碎在嘴边"
- "她没说话。只是把那张纸条叠了三折"
- "他第一次见她，没有笑。但他的袖子被她看见挽了三折"
```

出现直白情绪标签自动标 `severity=medium`，原因类别 `ai_flavor`（与 reviewer.md 兼容）。

### 5.2 禁止万能副词

```
❌ "缓缓" / "淡淡" / "微微" / "不由得" / "不禁" / "默默"
❌ "温柔地" / "深情的" / "冷酷的"

✅ 改用具体动作：
- 缓缓 → "她把手伸过去，又缩了回来"
- 淡淡 → "他的语气很平，像在说今天天气不错"
- 微微 → "她点头，幅度小到只有他看见"
```

万能副词出现次数 ≥3 次/章 → `severity=medium`。

### 5.3 禁止连续同句式

```
连续 ≥3 段使用相同句式结构（如每段都以"她"开头，每段都"动词+了+名词"）→ severity=medium
```

## 六、信息差硬指标

### 6.1 误会章信息差强制

```
误会章必须有 ≥1 处"读者已知但男主不知"的真相：
- 通过女主视角段 / 旁白 / 其他人对话透露
- 该信息差必须在章末钩子里仍保持
```

### 6.2 重逢章信息差强制

```
重逢章必须有 ≥1 处"读者已知但女主/男主不知"的过去细节：
- 通过她/他的旧物品 / 旧习惯 / 旧称呼暗示
- 该信息差必须让读者感到"心疼"或"愤怒"
```

### 6.3 替身/真身章信息差强制

```
替身/真身相关章必须满足以下 3 项中的 ≥2 项：
- 真身有专属细节（与替身完全不同的 1-2 个小习惯）
- 替身有动机缺陷（她/他知道自己在替代，但无法离开）
- 揭露方式有 ≥2 步（不是一次性揭穿）
```

## 七、反派硬指标

### 7.1 反派出场频次

```
每 5 章至少 1 次反派出场或被提及（对话中提到也算）
连续 5 章反派完全消失 → severity=medium, blocking=false
连续 10 章反派完全消失 → severity=high, blocking=true
```

### 7.2 反派功能性

```
每个反派必须有 ≥1 次以下功能：
- 提供信息（让主角知道新线索）
- 制造冲突（让主角必须做选择）
- 推动关系（让男女主必须合作或对立）

反派连续 3 章"无功能"出场（只为出场而出场）→ severity=low
```

### 7.3 反派动机（详见 playbook §五·5.8）

```
每个反派必须有 4 项中 ≥2 项：
- 可被理解的动机
- 可被欣赏的能力
- 可被同情的过去
- 可被尊重的退场
```

## 八、AI 执行指令

1. **任务书注入**：context-agent 在任务书第 5 段（"收在哪里"）前，追加一节"## 本章硬指标"——列出本章程式对应的字数、对话占比、糖点下限、章末钩子类型、信息差要求。
2. **起草后自检**：Step 2 起草完成后，main skill 必须自动跑一遍本文件的硬指标自检——不通过的标 `auto_handled`，让 review-pipeline 决定是否阻断。
3. **跨章联动**：cross-chapter-reviewer 在题材为言情时，按本文件 §三·3.2、§四·4.3、§七·7.1 计算连续性违规。
4. **档位调整**：用户用 `--fast` 时跳过 §五·5.3 句式检查；用户用 `--minimal` 时只检查字数下限 + 糖点下限。

</instructions>
